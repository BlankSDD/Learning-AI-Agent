# StudyMate 用例

## UC-001 回答具体问题

前置条件：

- 知识库已经导入。
- 模型配置有效。

步骤：

1. 用户在 CLI 输入问题。
2. 系统识别为 question。
3. 系统检索相关 Chunk。
4. 系统将问题、上下文和会话历史发送给模型。
5. 系统校验模型返回结构。
6. CLI 输出回答和引用。

成功结果：

- 回答来自检索上下文。
- 来源可以定位到文件和行号。

## UC-002 输入学习目标

输入示例：

~~~text
我想从零学习 AI Agent，希望一个月后能做出简单项目。
~~~

步骤：

1. 识别为 goal。
2. 从知识库检索 Agent 基础、工具调用、RAG、评估等资料。
3. 生成分阶段学习计划。
4. 每个阶段附上相关资料来源。

## UC-003 输入知识关键词

输入示例：

~~~text
LangGraph
~~~

步骤：

1. 识别为 keyword。
2. 返回关键词的简要解释。
3. 返回相关资料列表。
4. 给出推荐的下一步问题。

## UC-004 连续追问

对话：

~~~text
用户：什么是 RAG？
用户：它和微调有什么区别？
用户：那我的学习资料适合用哪一种？
~~~

验收重点：

- 后续问题可以使用当前 Session 的上下文。
- 重置 Session 后不能继续使用旧上下文。

## UC-005 没有足够依据

输入：

~~~text
根据我的资料，告诉我某个资料中不存在的事实。
~~~

期望：

- 系统明确说明资料中没有足够依据。
- 不编造不存在的引用。
- 可以建议用户补充资料或换一个问题。

## UC-006 CLI 命令

支持：

~~~text
/help
/sources
/reset
/quit
~~~

验收重点：

- 命令不会被发送给大模型。
- 未知命令有明确提示。
- /quit 正常结束进程。
