# StudyMate 产品范围

## 1. 产品定义

StudyMate 是一个命令行对话工具。用户将自己的学习资料放入本地知识库，然后用自然语言提问，或者输入学习目标和知识关键词。

系统检索相关资料后，调用大模型生成回答，并返回引用来源、可信度和下一步建议。

## 2. 用户价值

- 在自己的学习资料中快速找到相关内容。
- 获得带来源的解释，而不是无依据的模型回答。
- 将宽泛的学习目标拆成可执行的学习步骤。
- 通过命令行完成连续对话，不依赖复杂前端。

## 3. 第一版目标

第一版必须支持：

- 导入 Markdown 和 TXT 文件。
- 建立本地可检索知识库。
- 在命令行中进行连续对话。
- 支持问题、学习目标和关键词三类输入。
- 回答带有资料来源。
- 找不到依据时明确拒答。
- 支持查看来源、重置会话和退出。

## 4. 第一版明确不做

- 不处理公司保密资料。
- 不实现多 Agent。
- 不实现自动修改代码。
- 不接入 MCP。
- 不使用复杂的前端界面。
- 不默认接入互联网搜索。
- 不把整个知识库原文直接发送给模型。
- 不把落盘 Trace 自动作为模型记忆或知识库内容；跨进程会话恢复需要用户可控的单独设计。

## 5. 分阶段目标

### V0：固定 RAG Workflow

~~~text
输入 -> 检索 -> 上下文组装 -> 模型回答 -> 来源校验
~~~

### V1：Tool Calling

模型可以选择搜索资料、获取原文或制定学习计划。

### V2：带记忆的对话

保存当前会话和少量用户学习偏好。

### V3：Agent 行为

模型可以根据检索结果决定是否改写问题、再次检索或请求更多信息。

## 6. 非目标

StudyMate 的目标是学习和验证 Agent 应用工程方法，不是做成商业化知识库产品，也不是替代 Cursor、ChatGPT 或完整学习平台。
