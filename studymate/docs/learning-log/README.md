# 学习记录

这里保存 AI Agent 学习过程中的知识问答、项目决策和阶段性复盘。

## 记录原则

- 每条记录保留用户问题、回答结论和对 StudyMate 的影响。
- 知识性问答优先记录可复述的定义、边界和运行流程。
- 项目记录说明为什么做这个选择，以及当前实现状态。
- 不记录 API Key、完整 `.env` 内容、个人简历和其他敏感信息。
- 新增记录使用 `YYYY-MM-DD-topic.md` 命名。
